## 判定: 数値上はゲート通過。ただし証拠は弱く、「複数シード拡大に進む資格」と読むのが正確

事前登録の基準（A1 ≥ A0 + 2pt かつ A1 ≥ A2）への当てはめ:
- A1 − A0 = **+3.33 pt**（基準クリア、正味 +10 問）
- A1 − A2 = **+3.00 pt**（数値上クリア）

しかし以下の留保がすべて付く。基準は動かしていないが、結論の強さはここまでが限界である。

1. **ノイズと同程度の差**: n=300・1シードでは差の標準誤差は約 ±2.8 pt。+3.33 pt は約 1.2σ で、偶然でも出うる大きさ。
2. **A0 が悪化した上での比較**: A0 は step 0 から −1.0 pt 下がり、エントロピーが +0.147 と overshoot した。A1 の優位の内訳には「A0 の劣化」と「A1 の改善（step 0 比 +2.33 pt）」の両方が混ざっている。ただし A1 がエントロピーを step 0 水準に保った点は、E2-OPSD の診断（特権由来の自信が overshoot を招く）と整合する、機構的に意味のある観察である。
3. **A2 の脚は弱い**: A2 は事前登録した定義（τ を ℓ の較正値のまま Δ に適用）では重みが単一トークンへ完全集中し（ESS ≈ 0.0011）、2回の run とも生成中 assert で 40 ステップを完走できなかった（この集中自体は事前登録時に予測されていた）。20ステップ時点の代替評価との比較であり、ステップ数も揃っていない。公正な A2 には Δ 自身の分布での τ 再較正が要る。
4. **A1 の作用の解釈は未分離**: A1 の重み付き損失は最初から約 0.0001 の桁で、重みは発散ほぼ 0 の位置に集中した。つまり A1 は「leakage の大きい位置を弱める」と同時に「実効的にモデルをあまり動かさない」方向にも働く。位置特異的な効果か、単なる減衰効果かは、重みを位置シャッフルした対照なしには分離できない。

## AVSD 死角の診断: 主張は支持されなかった

- 「ℓ 上位25% かつ J 中央値以下」の割合は **2.88%** で、事前に固定した読み（≥50%）に遠く届かなかった。この operationalization の下では「AVSD は高 leakage 位置の過半を見逃す」は**棄却**する。
- 留保: J の中央値は 2.83e-06 とほぼ 0 で、「中央値以下」という物差し自体が弱かった面はある。ℓ と J の相関は 0.233 と低く、ℓ が J と異なる情報を持つこと自体は示唆されるが、「死角」を動機づけの中心に置くのは現データでは無理がある。
- 帰結: アイデア3の動機づけは「AVSD の死角」から「**特権なし参照への発散で重み付けると OPSD の overshoot を抑え、精度も落とさない**」へ組み替えるのが実測に忠実。ただしこの領域は E2-OPSD の動機（entropy overshoot 対策）と隣接するため、新規性の主張は信号の違い（エントロピー差ではなく特権参照への KL）に置く必要がある。

## 次の一手（事前登録の手順では「通過 → 複数シード拡大の提案」）

安くて決定的な順に:
1. **シャッフル重み対照（1シード、約2〜3時間）**: A1 と同じ重み分布を位置だけ無作為に入れ替える。これが A1 に並ぶなら位置特異性は死に、アイデア3は実質終了。A1 が勝てば「leakage の位置情報が効いている」ことが初めて言える。
2. **追加シード拡大（約10時間）**: A0/A1 を追加2シード＋公正 A2（τ 再較正）を 1シード。1 の結果が良ければ実施。

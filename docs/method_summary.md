## 1. 一言で言うと

自己蒸留（OPSD）では、教師は「参照解（特権情報）を見た状態」で分布を出すため、
生徒が本番で再現できない自信が混ざる。その混ざり具合をトークンごとに測り、
**特権依存の大きい位置の学習を弱める**重み付けを蒸留損失に掛ける手法。

## 2. 解く問題

- ベース手法 OPSD（On-Policy Self-Distillation）は、生徒自身の生成（on-policy ロールアウト）に対し、
  参照解 z を条件付けた教師分布への蒸留を行う。
- 問題は「特権の錯覚（privilege illusion）」：教師の分布は参照解を知っているからこその形をしており、
  その自信は生徒の prefix からは再現できない。E2-OPSD 自身の分析も
  「教師の解答固有の手がかりへの自信は生徒 prefix に転移しない」と診断している。
- 既存の対処は、参照解を exemplar に置き換える（E2-OPSD）、ビュー同士の食い違いで
  ゲートする（AVSD）など。本手法は「転移しない信号を、測って弱める」という直接の対処を取る。

## 3. 手法

### 3.1 信号：特権 leakage ℓ_t

トークン位置 t ごとに、

```
ℓ_t = D_KL( p_T(· | prefix, z) ‖ p_ref(· | prefix) )
```

- `p_T`：OPSD の教師。prefix と参照解 z で条件付けられた分布。
- `p_ref`：**凍結した初期モデル**を**問題文（prefix）のみ**で条件付けた分布。特権を一切見ておらず、学習もしない。
- つまり「参照解を見たことで教師の分布がどれだけ動いたか」を全語彙 KL で測る。これが leakage の定義。
- 信号は学習時と同じ温度（1.1）でスケールされた分布で計算する。

### 3.2 重み

```
w_t = exp(−ℓ_t / τ)
```

- leakage が大きい位置ほど重みは 0 に近づき、その位置の学習が弱まる（方向は**減少**）。
- `τ` は学習前に固定する：初期モデルで 32 問のロールアウトを生成し、全位置の ℓ_t の**中央値**を τ とする。
  実測で τ = 5.306877e-04。以後、全条件・全ステップで凍結し、事後に動かさない。
- 重みは損失項**全体**に掛ける（部分的な項ではない）。数値安定化として、重み付き平均が
  共通の定数倍に不変であることを利用し、指数は最大値でシフトして計算する（log-sum-exp 型）。

### 3.3 ベース手法側の条件（OPSD 公式設定を保持）

- OPSD 公式コード（commit ae7d251）、β=0（forward KL）、pointwise clip 0.05、fixed_teacher。
- モデル: Qwen3-1.7B + LoRA (r64)。学習率 5e-6。実効バッチ 8、生成長 512。

### 3.4 設計上の死守点

- **参照は凍結かつ特権なし**。もし p_ref を訓練中の生徒自身にすると、ℓ_t は損失項そのものに
  退化し、重み付けは OPSD の pointwise clipping の連続版（＝自己参照的な「損失の大きさによる
  重み付け」）になって独立した内容が消える。この形に限るのが本手法の定義の一部。

## 4. 先行研究との差分（反証を経た正直な範囲）

主張は当初 (a) 測ること (b) 重み付け (c) 統一視点 の3つだったが、反証で大半が潰れた。

| 主張 | 判定 | 理由 |
|---|---|---|
| (a) leakage のトークン単位の定量化 | 死亡 | RLSD の Δ_t（サンプルトークンの log 確率差）がほぼ同量で、ℓ_t はその教師分布での期待値に等しい。情報理論的な定量化も既出 |
| (c) 既存手法を特殊ケースとする統一視点 | 死亡 | 分野で既に整理が始まっていた |
| (b) leakage による連続的な損失重み付け | **狭く生存** | 形式自体は E2-OPSD の AGD 等が実装済み。ただし既存の重み付け信号は (i) GRPO advantage への適用（RLSD, OCSD）、(ii) エントロピーギャップ（E2）、(iii) 増幅方向、のいずれか |

生き残った差分は次の3点の組み合わせのみ：

1. **信号**: 凍結した特権なし参照モデルに対する全語彙 KL（サンプル log 比でもエントロピーギャップでも特権同士の差でもない）
2. **方向**: leakage の大きいトークンを**弱める**（既存研究はほぼ全て増幅方向。この符号で勝てるかは未検証の実証問題だった）
3. **適用先**: 蒸留損失の項全体（advantage 等への適用ではない）

AVSD との構造差: AVSD は参照解から作った3ビュー同士の食い違いしか測れないため、
全ビューに共通する「参照解そのもの由来の特権依存」は原理的に素通りする。本手法の信号は
特権を見ていない凍結モデルとのズレなので、その共通分も捕まえる。
（ただし後述の通り、この死角が実際に大きいという主張は実験で支持されなかった。）

## 5. 実験条件（ゲート1の再現用パラメータ）

- 学習データ: 公式データ [0, 960)、40 ステップ（当初案 120 を速度実測のため削減。判定基準は不変）。
- 評価: held-out [960, 1260) の 300 問、greedy 生成（生成長 512）、\boxed 抽出＋正規化一致。
- シード 42（全条件共通）、τ = 5.306877e-04。
- 対照条件: A0 = 素の OPSD、A1 = 本手法、A2 = 信号だけをサンプルトークンの Δ_t に替えた
  アブレーション（「全語彙で測ること」の寄与の分離用）、A1S = A1 の重みを行内で
  シャッフルした対照（「位置情報か、単なる減衰か」の分離用）。

## 6. ここまでの証拠

### ゲート1（held-out 300問、1シード）

| 条件 | 正答率 | 平均エントロピー |
|---|---|---|
| 学習前（初期モデル） | 12.7% | 0.2018 |
| A0 素の OPSD | 11.7% | 0.3488 |
| **A1 本手法** | **15.0%** | **0.2146** |
| A2 アブレーション（20ステップ代替評価） | 12.0% | 0.2058 |

- 事前登録基準（A1 ≥ A0 + 2pt かつ A1 ≥ A2）を数値上はクリア（A1−A0 = +3.33pt）。
- A0 は学習でエントロピーが大きく増えて（overshoot）精度が落ちたのに対し、A1 は
  エントロピーを学習前水準に保ったまま精度を上げた。当初の見立てと合う動き。
- 留保: A1 の優位の一部は「A0 が悪化した分」。A2 は重みが単一トークンに集中して
  学習が2回とも途中で落ち、完走できなかった（対照として弱い）。

### シャッフル対照 A1S（位置特異性の決定的確認）

| 条件 | 正答率 | 平均エントロピー |
|---|---|---|
| A1S（重みの位置だけシャッフル） | 11.33% | 0.3311 |

- A1S は A0 と1問差の水準に落ち、事前登録の「位置情報が生存」の分岐に該当
  （A1S ≤ 12.7% かつ A1 − A1S = +3.67pt ≥ 2pt）。「効いていたのは単なる減衰効果」
  という代替説明は退けられた。エントロピーも A0 並みで、overshoot 抑制自体が
  位置特異的という読みと一致。

### 支持されなかった主張

- 「AVSD は高 leakage 位置の過半を見逃す」という死角の主張は、診断の結果 **2.9%**
  （基準 50%）で支持されなかった。この売り文句は捨てた。残る主張は
  「OPSD の暴走（エントロピー overshoot）を位置特異的に抑える重み付け」という地味なもの。

### 全体への留保

- 300問・1シードでは二項標準誤差が約 ±1.9pt あり、上記の差はノイズと同程度の
  大きさを含む。40ステップは公式の言うピーク（100ステップ以内）より手前。

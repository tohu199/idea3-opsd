# シャッフル重み対照 A1S — アイデア3 ゲート1の決定的確認（事前登録）

作成: 2026-11-09（ゲート1判定の直後、実行前に固定）
前提: ゲート1判定 `reports/2026-11-09_idea3-gate1-verdict.md` —
A1 15.00% vs A0 11.67%（差 +3.33pt、基準 +2pt は数値上クリア）だが、
n=300・1シードで誤差 ±2.8pt、A0 が学習で悪化した上での比較、A2 は完走不能。
未分離の論点（判定ファイル §4）: A1 の重み付き損失は最初から約 0.0001 の桁で、
重みは発散ほぼ 0 の位置に集中した。つまり A1 は「leakage の大きい位置を
弱める」と同時に「実効的にモデルをあまり動かさない」方向にも働く。
位置特異的な効果か、単なる減衰効果かはシャッフル対照なしには分離できない。

## 設計

- **A1S**: A1 と完全同一条件（τ=5.306877e-04、fullkl、40ステップ、シード42、
  データ [0,960)、LR 5e-6、β=0、clip 0.05、実効バッチ8、生成長512）。
  唯一の違い: 各マイクロバッチで重み w_t を**行ごと・マスク位置内でのみ**
  無作為に並べ替えてから重み付き平均を取る。
- 並べ替えは学習 RNG とは独立の Generator（シード 20261109）で行うため、
  生成・最適化の乱数は A1 と変わらない。重みの多重集合は行ごとに完全保存
  されるので、ESS・重み平均・損失スケールは不変。壊すのは位置対応だけ。
- 実装: `code/patch_opsd_shuffle.py`（PC 上で gate1 済みコードに適用、
  アンカー不一致なら即 abort）。新規 leakage_mode `fullkl_shuffle`。
  注意: patch_opsd3 が重み計算を max-shift 指数に変えているため、
  アンカーは patch3 適用後の文面に合わせてある（検証済み）。

## 実行手順（PC bt-gaming、要フォアグラウンド SSH — Gate1 と同じ運用）

1. PC がオンラインで、実行中のアームがないことを確認する
   （`check_arm.sh` / `nvidia-smi`。本ファイル作成時はバックグラウンド
   準備中の制約で SSH 確認ができなかったため、実行時に必ず確認すること）。
2. `patch_opsd_shuffle.py` を PC `~/muse/idea3-opsd/` へ送り実行。
   `grep -n fullkl_shuffle opsd_trainer.py` が 3 ヒットであること。
3. **1ステップ・プローブ**: A1S を MAXSTEPS=1 で走らせ、最初のマイクロ
   バッチの `leak_stats_fullkl_shuffle.jsonl` の ESS が A1 の
   `leak_stats_fullkl.jsonl` の最初の行と一致することを確認する
   （同じ初期モデル・同じデータ順・同じ生成のため、一致するはず。
   不一致ならシャッフル実装か RNG 分離に誤りがあり、続行しない）。
4. 本番: `run_arm.sh A1S fullkl_shuffle 0.0005306877 40 2 4 steps <A1と同じlogging_steps>`
   （保存・ログ間隔は A1 の呼び出しと同一にすること。A1 の実績:
   学習 wall 6,197 秒、VRAM ピーク 8,004 MiB）。
5. 評価: `eval_harness.py --adapter <A1S の checkpoint-40（A1 と同じ配置）>`
   `--out gate1_out/eval_A1S.json`（held-out [960,1260) 300問、greedy、
   A1 の実績 wall 1,339 秒）。正答率と平均エントロピーを記録する。

## 判定基準（事前登録 — 実行前に固定し、結果を見て動かさない）

主指標は held-out 300問の正答率。基準値: A1 15.00%、A0 11.67%、step 0 12.67%。

- **A1S ≥ 14.0%**（A1 との差 1pt 以内）→ **位置特異性は死**。効いていたのは
  leakage の位置情報ではなく単なる弱め効果。アイデア3は実質終了として
  記録し、次はアイデア2（WM蒸留）か新規スキャンへ。
- **A1S ≤ 12.7%**（step 0 水準以下）かつ A1 − A1S ≥ 2pt → **位置情報が生存**。
  複数シード拡大へ進む（A0/A1 を追加2シード＋公正 A2（τ再較正）を 1シード、
  判定ファイルの手順2、約10時間）。
- **12.7% ＜ A1S ＜ 14.0%** → 曖昧。主張しない。複数シード拡大にシャッフル
  アームを同梱して判断する（予算が許せば）。

副次指標（平均エントロピー）: A1 0.2146、A0 0.3488、step 0 0.2018。
A1S のエントロピーが A1 並みなら overshoot 抑制は位置によらない減衰効果、
A0 並みなら抑制自体が位置特異的、という読み分けに使う。
